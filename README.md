# Which Famous Writer Are You? — W4GZ Quiz

A personality quiz about writing style from **Writing for Gen Z (W4GZ)**.
Students answer 12 questions about the stories they love, the sentences they'd write and how they work, then find out which of 12 remarkable writers from history shares their style.

*Create narratives worth living.*

## The 12 writers

| | Planner | Explorer | Reviser |
|---|---|---|---|
| **Heart** (characters & feelings) | Charles Dickens | Murasaki Shikibu | Jane Austen |
| **Spark** (plot & drama) | William Shakespeare | Fyodor Dostoevsky | Ernest Hemingway |
| **World** (places & history) | Leo Tolstoy | Gabriel García Márquez | Victor Hugo |
| **Voice** (words & style) | Lu Xun | Friedrich Nietzsche | Du Fu |

Each result shows the student's writing style, a true story about how that writer worked, a short biography, famous works, a book to start with, a strength, something to watch out for and a writing exercise. It also shows a runner-up writer and the student's top 5 "writer mix".

## How scoring works

- Each answer names 1–3 writers; each named writer gets +1 point.
- "Your main character is most likely…" gives +3 and breaks ties.
- The writer with the most points is the result; second place is the runner-up.

## Run it

It's a single file with no build step: open `index.html` in a browser, or turn on **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root) to get a shareable link.
